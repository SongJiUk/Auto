# 서식 채우기 프로그램 기획

## 한 줄 요약
매일 반복하는 엑셀·한글 서식의 정해진 칸에 그날의 값을 넣고, 어제 파일의 누계를 이어받아 날짜별 폴더에 저장하는 PC 프로그램.

## 왜 필요한가
- 매일 아침 공사일보, 출력일보, TBM일지, 사진대지를 손으로 수정한다.
- 바꾸는 칸은 매일 같다(날짜, 날씨, 작업사항, 인원, 장비, 덤프, 공정율, 사진).
- 인원과 장비는 매일 달라서 입력까지 없앨 수는 없다. 자동화 대상은 "같은 칸에 같은 방식으로 넣는 반복 작업"이다.

## 매일 하는 일 (사용자가 말한 그대로)
1. 공사일보 (아침)
   - 날짜, 날씨, 금일 작업사항을 바꾼다.
   - 장비 투입현황: 새로 만들 때 누계를 전일로 옮기고, 금일 값을 더한다.
   - 인원 투입현황: 장비와 같다. 사용자가 인원을 알려 주면 그대로 반영한다.
   - 덤프(폐기물 반출)와 공정율도 같은 방식이다.
2. 출력일보: 인원을 알려 주면 그대로 채운다. 수장재 인원은 넣지 않는다.
3. TBM일지 (아침): 작성일자, 인원, 내용을 바꾼다. 내용은 사용자가 알려 주는 대로. 세부 기준은 나중에 사용자가 정해 준다.
4. 사진대지: 사용자가 "수장재", "장비"라고 라벨을 붙여 보낸 사진을 해당 자리에 넣는다.

## 구조
```
설정(최초 1회) -> 매일 입력 -> 생성 -> 날짜별 폴더에 저장
```
- 설정: 서식 파일 지정 -> 칸에 이름 붙이기(시트, 셀 주소) -> 규칙 지정
- 규칙 종류: 값 입력 / 날짜 형식 변환 / 전일 = 어제 파일의 누계 / 누계 = 전일 + 금일 / 한 번 입력한 값을 여러 문서에 반영 / 목록(여러 줄) 채우기
- 매일 입력: 날짜, 날씨, 작업사항, 인원, 장비, 덤프, 공정율, 사진
- 모든 규칙은 설정 화면에서 바꿀 수 있어야 한다. 코드에 고정하지 않는다.

## 기술 방침
- C# WPF (.NET 8), 로컬 파일만 처리. 서버와 외부 전송 없음.
- 엑셀은 Open XML SDK로 셀 값만 수정한다. 이미지, 도형, 도장은 건드리지 않는다.
- 사진대지는 새로 삽입하지 않고, 이미 자리가 잡힌 두 이미지(xl/media 안 파일)를 새 사진으로 바꿔 끼운다. 위치와 크기는 유지한다. 먼저 이 방식이 되는지 시험한다.
- 한글(hwpx)은 압축을 풀어 XML 문자를 직접 바꾸고 다시 압축한다(mimetype 파일을 맨 앞에, 무압축으로).

## 단계
1. 엔진: 설정된 칸에 값을 넣고 어제 누계를 이어받는다. 샘플로 검증한다. (화면 없이 테스트로 확인)
2. 입력 화면(WPF): 날짜, 날씨, 인원, 장비 등 입력
3. 사진 교체: 사진대지의 수장재·장비 사진
4. 한글(hwpx) 서식 지원
5. 노임대장 연동: 오늘 출근자 한 번 입력으로 공사일보, 출력일보, TBM, 노임대장 출역이 함께 채워지게 한다.
6. 모바일(사진과 입력 전송), Claude API 기능(출근부 사진 이름 인식)은 가장 나중에

## 1단계 완료 기준
- `samples/` 의 11/04 공사일보로 11/05 파일을 `output/`에 생성한다.
- 장비·인원의 전일/누계가 규칙대로 이어지고, 합계 수식 결과가 맞다.
- TBM일지의 작성일자·인원이 바뀌고, 참석율이 계산된다.
- 생성 파일을 엑셀로 열었을 때 이미지와 서식이 원본과 같다(개수·위치 비교와 렌더링 비교).
- 규칙이 설정 파일(JSON)로 분리되어 있다.

## 아직 정해지지 않은 규칙 (설정으로 처리, 추측 금지)
- 덤프 총 반출수량 = 누계 x 17 의 의미 (규격은 15m3로 표시됨)
- ~~공정율·덤프의 "전일" 칸(`P36`, `E36`)에 어제 실적을 넣고 누계(`R36`, `G36`)에 더하는 방식이 맞는지~~ → 맞음 (2026-11-22 사용자 확인: 누계 = 어제 누계 + 전일반출). 금일 열 없는 표는 전일 열을 매일 입력 칸으로 자동 인식 (`HeaderDetector`)
- 수장재 인원이 공사일보 인원 투입현황에 들어가는지 (현재 금일 12명 = 출력일보 12명이고, TBM은 15명)
- 출력일보 직종(소장·차장·대리)을 공사일보 "관리자"로 세는지
- 표 밖 숫자(공사일보 `W34:Y38` 근처)를 지워도 되는지
- TBM일지 내용·위험성평가·준수사항의 기준 (사용자가 나중에 제공)
