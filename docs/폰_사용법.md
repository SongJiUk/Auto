# 폰으로 입력하고 문서 자동으로 만들기

폰에서 장비·인원·사진을 올리면, 회사에 켜 둔 PC 의 업무자동화가 1분 안에 읽어서 PC 설정 그대로 문서를 만들어 구글 드라이브 `output` 에 저장합니다.

```
폰 (웹앱)  ──올리기──▶  드라이브 FormFiller_inbox  ──1분마다 확인──▶  켜 둔 PC (업무자동화)  ──▶  드라이브 output\문서
   ▲                                                                       │
   └──────────────── 결과(✅ 만든 파일 이름 / ⚠ 문제) ◀── result.json ──────┘
```

- 파일 위치·칸·규칙은 **PC 의 📁 문서 관리에서만** 정합니다. 폰 화면은 그 설정을 따라 자동으로 바뀝니다.
- PC 가 꺼져 있으면 올린 입력은 기다렸다가, 다음에 PC 에서 업무자동화를 켤 때 만들어집니다.

---

## 처음 한 번만: 설치 (PC 에서 10분)

### 1. 웹앱 만들기
1. PC 크롬에서 회사 업무용 구글 계정으로 <https://script.google.com> 접속 → **[새 프로젝트]**
2. 왼쪽 위 프로젝트 이름을 `업무자동화 폰 입력` 으로 바꿉니다.
3. `Code.gs` 내용을 모두 지우고, 저장소의 `phone/Code.gs` 내용을 붙여 넣습니다.
4. 왼쪽 **파일 ＋ → HTML** → 이름을 `Index` 로 (확장자 없이) → `phone/Index.html` 내용을 붙여 넣습니다.
5. 💾 저장 (Ctrl+S)

### 2. 배포
1. 오른쪽 위 **[배포] → [새 배포]** → 톱니바퀴 → **웹 앱**
2. 설정
   - 설명: `폰 입력`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만** ← 반드시. 다른 사람은 주소를 알아도 못 엽니다.
3. **[배포]** → "액세스 승인" → 내 계정 선택 → "Google에서 확인하지 않은 앱" 이 나오면 **[고급] → [업무자동화 폰 입력(으)로 이동]** → **[허용]**
   (내가 만든 스크립트라 구글 심사를 안 받았다는 뜻입니다. 이 스크립트는 드라이브의 `FormFiller_inbox` 폴더만 읽고 씁니다.)
4. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사해서 카톡 나에게 보내기 등으로 폰에 보냅니다.

### 3. 폰 홈 화면에 붙이기
- **안드로이드 (크롬)**: 주소 열기 → 오른쪽 위 ⋮ → **[홈 화면에 추가]**
- **아이폰 (사파리)**: 주소 열기 → 아래 공유 버튼 □↑ → **[홈 화면에 추가]**
- 처음 열 때 구글 로그인이 나오면 **PC 와 같은 구글 계정**으로 로그인합니다.

### 4. PC 준비
- 회사 PC 에서 바탕화면 **업무자동화** 를 켜 둡니다. 켜 두기만 하면 됩니다 (최소화 OK, 창 닫으면 안 됨).
- 처음 켜면 드라이브에 `FormFiller_inbox` 폴더와 폰 양식이 생깁니다. 폰 화면 맨 위에 `PC 양식: 11/23 08:31 (PC이름)` 이 보이면 준비 끝.
- 절전 모드가 되면 멈춥니다: 설정 → 시스템 → 전원 → **절전 모드: 안 함** (화면 꺼짐은 괜찮음).

## 매일 쓰는 법

### 아침 (PC)
1. 출근해서 PC 켜고 **업무자동화** 실행 → 그대로 둡니다.

### 현장 (폰)
1. 홈 화면의 **업무자동화 폰 입력** 열기
2. **날짜** 확인 (기본 오늘)
3. **만들 문서** 체크 (오늘 만들 차례인 문서는 미리 체크됨)
4. 항목 입력
   - **장비 표**: 장비마다 `−` `+` 로 오늘 대수. 어제 목록이 미리 떠 있고, `↻ 어제와 같게` 로 어제 대수 한 번에. 새 장비는 이름·규격 넣고 **+ 추가**
   - **인원 명단**: 오늘 나온 사람 체크 (어제 온 사람은 미리 체크됨). 처음 온 사람은 이름·직종 넣고 **+ 사람**
   - **작업사항**: 한 줄에 하나씩
   - **사진**: 칸마다 📷 → 찍기 또는 앨범에서 고르기. 측정 칸은 값(dB)도 입력. 잘못 고르면 ✕
5. 맨 아래 **[올리기]**
6. 화면 아래에 `⏳ PC 처리 대기` → 1~2분 뒤 `✅ 만들었습니다: 26.11.23 공사일보….xlsx`
7. 폰의 **구글 드라이브 앱 → 업무자동화 → output** 에서 바로 열기·공유

### PC 에서 확인
- 메인 화면 위 띠 오른쪽에 `📱 폰 입력으로 만듦 09:12: …` 가 뜹니다.
- 고칠 게 있으면 PC 에서 그 날짜로 고쳐서 [파일 생성] 하면 덮어씁니다.

## 문제가 있을 때

| 폰 화면 | 뜻 / 할 일 |
|---|---|
| `FormFiller_inbox 폴더가 없습니다` | PC 에서 업무자동화를 한 번도 안 켰음 → PC 에서 켜기 |
| `PC 양식은 11/22 기준입니다` | 오늘 PC 가 아직 안 켜짐. 올려 두면 PC 켤 때 만들어짐 |
| 계속 `⏳ PC 처리 대기` | 회사 PC 가 꺼졌거나 업무자동화가 닫힘 / 절전 모드 |
| `⚠ 숫자 … 범위 밖` 등 | 입력을 고쳐서 다시 올리기 |
| `⚠ 사진 파일이 아직 없습니다` | 드라이브 동기화가 늦음. 30분까지 기다렸다 다시 시도함 |

- 같은 날 두 번 올리면 **나중에 올린 것으로 다시 만듭니다** (파일 덮어씀).
- 사진은 폰에서 긴 변 1600px 로 줄여서 올립니다 (데이터 절약).
- 전파가 없는 곳에서는 올리기가 안 됩니다. 사진은 찍어 두고 나중에 앨범에서 고르면 됩니다.

## 웹앱 코드를 고쳤을 때 (Claude 가 `phone/` 을 바꾼 경우)
script.google.com → 파일 내용 다시 붙여 넣기 → 저장 → **[배포] → [배포 관리] → ✏ → 버전: 새 버전 → [배포]**. 주소는 그대로라 폰은 다시 안 붙여도 됩니다.
