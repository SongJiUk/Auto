# PC에서 할 일 (체크리스트)

> 클라우드 세션에서는 화면을 띄울 수 없어서, 아래는 **윈도우 PC에서 직접** 해야 합니다.
> 끝난 항목은 `[x]` 로 바꾸고, 문제가 있으면 스크린샷·증상을 Claude 에게 보내 주세요.
> 마지막 정리: 2026-11-18

---

## 0. 준비 (한 번)

- [ ] **최신 exe 받기**: GitHub → Actions → 맨 위 `build` (main) → 아래 **Artifacts** 의 `업무자동화-exe` (zip, 7일 보관)
  - 또는 PC 에서 `git checkout main` → `git pull` → `빌드.bat`
- [ ] 드라이브의 exe 를 바로 바꾸지 말고, **바탕화면 같은 곳에 시험용으로 따로** 풀어서 실행
  - 시험용은 드라이브 밖이라 상단에 주황 띠("드라이브 밖에서 실행 중")가 뜨는 게 정상
  - 시험용 폴더에 드라이브의 `config.json`·`서식\` 을 **복사**해 두면 실제 설정으로 시험 가능 (원본은 건드리지 않음)
- [ ] 바탕화면 탐색기 확인: 2026-11-14 화면 시험 때 입력이 탐색기(`F:\...\1.업무일지`)로 들어갔을 수 있음 → 이름 바뀐 파일·폴더 없는지

## 1. 화면이 뜨는지 (스크린샷 요청)

- [ ] 프로그램 실행 → 첫 화면 스크린샷
- [ ] 첫 단계 "오늘 생성할 문서"가 **📅 매일 업무 / 🗓 주기 업무** 로 나뉘어 보이는지
- [ ] 상단 **[☁ 구글 드라이브]** → 점검 줄이 ✔ 인지 (시험용 폴더면 "프로그램 위치" 만 ⚠ 가 정상) → 스크린샷
- [ ] 작업 표시줄에서 Google Drive 를 끄고 프로그램 다시 실행 → 주황 띠 → 눌러서 ✖ 와 [다운로드 페이지 열기] 보이는지 (확인 후 Drive 다시 켜기)

## 2. 예전 방식 그대로 동작하는지 (지금 쓰는 문서 3개)

- [ ] 공사일보·출력일보 / TBM / 소음측정일지 체크 → 장비·인원 입력 → [파일 생성]
- [ ] 생성 결과 창에 **"(자동 검증 통과)"** 가 붙는지 (주황 경고가 나오면 그 문구 그대로 보내 주기)
- [ ] 만든 파일을 Excel 로 열어 날짜·누계·사진·도장 그림이 정상인지
- [ ] 장비·인원 표에서 **칸을 한 번 클릭**하면 바로 입력되는지 (안 되면 두 번 클릭은 되는지)

## 3. 블록 방식 시험 (새 기능)

- [ ] ⚙ 설정 → 공사일보·출력일보 [✏ Excel 에서 편집] → 위쪽 주황 상자의 **[블록 방식으로 바꾸기]** → 카드들이 블록으로 바뀌는지 → **시험용 폴더에서만** [저장]
- [ ] 메인 화면 왼쪽에 **"항목 입력"** 단계가 생기고, 날씨·금일 작업·장비·인원 카드가 나오는지
- [ ] 같은 날짜로 생성 → 예전 방식으로 만든 파일과 값이 같은지 (Excel 에서 나란히 비교)
- [ ] 새 블록 추가해 보기 (아래 중 2~3개):
  - [ ] ➕ 숫자 누계 "덤프 반출": 오늘 칸(E36) → 누계 칸(G36) 클릭 → 전일 칸 [건너뛰기]
  - [ ] ➕ 숫자 누계 "철거동": P36 → R36
  - [ ] 👥 명단 "출근자": **출력일보 시트로 넘어가서** A4:D23 드래그 → [확인] → 열이 **자동으로** 직종 B · 성명 C · 작업내용 D 로 잡히는지 (카드에 초록 "머리글에서 찾음" + `[출력일보]`)
  - [ ] 📊 표: 공사일보 A20:K32 드래그 → [확인] 만으로 이름 A · 규격 D · 전일 F · 금일 H · 누계 J 가 잡히는지
  - [ ] 인원 표 카드의 "금일 값" 에서 `출근자` 고르기 → 짝짓기 체크 표가 나오는지 → 관리자 줄에 소장·차장·대리 체크
  - [ ] 🧮 계산 카드의 "쓸 항목" 이 체크박스로 나오는지
- [ ] 메인 "항목 입력"에서 명단 체크 → **인원 표 금일이 바로 바뀌는지**, 덤프 누계가 "전일 + 오늘 = 누계" 로 보이는지
- [ ] 날짜를 하루 넘겨 다시 생성 → 누계·전일이 이어지는지
- [ ] 이상한 점·헷갈린 점 메모 (처음 쓰는 사람 입장에서) → Claude 에게 전달
