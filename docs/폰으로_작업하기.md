# 폰으로 작업하기 (집 PC 원격 조종)

> 집 PC를 켜 두고, 폰 Claude 앱에서 그 PC의 Claude Code에 접속해 작업한다.
> PC가 작업장, 폰은 리모컨. 빌드·실행·화면 캡처·드라이브 배포까지 전부 집 PC에서 실제로 돈다.
> 정리: 2026-11-19

---

## 왜 이 방법인가

| | 폰 앱 Code (클라우드) | **원격 조종 (이 방법)** |
|---|---|---|
| 코드 수정·커밋·push | O | O |
| 엔진 테스트 (`dotnet test`) | O | O |
| WPF 빌드 | X (push 후 GitHub Actions) | **O (바로)** |
| 프로그램 실행 + 화면 캡처 | X | **O** (Claude 가 보고 글로 알려 줌) |
| 실제 서식으로 시험 | X (서식은 GitHub 에 없음) | **O** |
| 드라이브 exe 교체 (`deploy`) | X (`G:` 없음) | **O** |
| PC 전역 설정·메모리 (`~/.claude`) | X | O |

클라우드 방식은 PC 를 못 켜 둘 때만 쓴다.

---

## 1. PC 에서 켜기 (작업 시작할 때 한 번)

PowerShell 을 새로 열고:

```powershell
cd "C:\Users\wldnr\OneDrive\바탕 화면\Auto"
claude remote-control --name 업무자동화 --permission-mode auto
```

- 처음 물어보는 **Spawn mode** 는 `[1] same-dir` (지금 폴더에서 바로 작업. worktree 는 세션 여러 개를 동시에 돌릴 때만)
- `--permission-mode auto`: 위험한 작업만 확인을 묻는다 (폰에서 승인 누르는 횟수가 줄어듦)
- **이 PowerShell 창은 닫지 않는다** (최소화는 괜찮음). 닫으면 원격 연결이 끊긴다
- 4시간 안에 같은 세션에 다시 붙으려면: `claude remote-control -c`

### 켜 두기 전 확인
- 절전: 이 PC(데스크톱)는 전원 연결 시 절전 "안 함" 이다 (2026-11-19 확인). 다른 PC 면 설정 → 시스템 → 전원 에서 "절전 모드 안 함"
- 화면 잠금(Win+L)을 해도 작업은 돌지만, **잠긴 상태에선 프로그램 화면 캡처가 안 될 수 있다** (아직 시험 안 함). 캡처가 필요하면 잠그지 않는다
- 집 PC 에서 프로그램을 켜 둔 채 회사 PC 에서 설정을 바꾸지 않는다 (나중 저장이 덮어씀). 화면 시험은 바탕화면 `업무자동화_시험\` 폴더에서

## 2. 폰에서 접속

Claude 앱 → **Code** → 세션 목록에서 **업무자동화** → 대화 시작.

새 세션은 전에 한 대화를 기억하지 못한다. 대신 `CLAUDE.md` 의 "남은 할 일"·"마지막 작업" 에 이어 갈 곳이 적혀 있으니 첫 마디는 이렇게:

```
CLAUDE.md 읽고 남은 할 일 맨 위부터 이어서 해줘. 폰이라 답은 짧게
```

### 자주 쓰는 말
| 하고 싶은 것 | 이렇게 말하기 |
|---|---|
| 화면 확인 | `빌드해서 시험용 폴더에서 켜고 캡처해서 어떻게 보이는지 알려줘` |
| 실제 서식으로 생성 시험 | `시험용 폴더에서 오늘 날짜로 TBM 만들어 보고 xlsx-check 해줘` |
| 배포 | `배포해줘` (빌드·테스트 → push → 드라이브 exe 교체, 단계마다 확인을 묻는다) |
| 하루 정리 | `작업 정리해줘` (CLAUDE.md·작업일지 갱신) |
| PC 끄기 | `컴퓨터 꺼줘` |

---

## 3. 끝낼 때

1. `작업 정리해줘` → 다음에 이어 갈 곳이 CLAUDE.md 에 남는다
2. `컴퓨터 꺼줘` → `shutdown /s /t 60` (1분 뒤 꺼짐). 1분 안에 `취소해줘` → `shutdown /a`
   - **꺼지면 폰에서 다시 켤 수 없다** (원격 켜기는 Wake-on-LAN 등 따로 설정해야 함). 그날 작업이 끝났을 때만

## 한계

- **캡처 이미지는 폰에 안 보일 수 있다.** Claude 가 캡처를 보고 글로 설명한다 (글자 잘림, 배치, 버튼 유무 등). 서식에 이름 등 개인정보가 있어 이미지를 웹에 따로 올리지 않는다
- Excel 클릭 지정처럼 마우스로 하는 동작은 UI 자동화로 흉내만 낸다. 쓰기 편한지는 결국 PC 앞에서 직접 써 봐야 안다
- 내 눈으로 화면을 보고 싶으면 원격 데스크톱 앱(예: Chrome 원격 데스크톱)을 PC·폰에 따로 설치한다

**추천 흐름**: 폰(원격 조종)으로 만들고 고치기 → 주말·퇴근 후 PC 앞에서 한 번 직접 써 보기 → `배포해줘`
